# Homebrew tap for OpenFilmKit

[OpenFilmKit](https://github.com/aidansiegel/OpenFilmKit) is free film scanning and negative
conversion from the command line, built on SANE.

**Nothing to install yet.** OpenFilmKit is in early development; this tap is a placeholder. Once
there's a release, installing will be:

```sh
brew install aidansiegel/openfilmkit/openfilmkit
```

The formula will build OpenFilmKit's own patched SANE runtime alongside it (kept separate from
Homebrew's `sane-backends`), so nothing else on your system changes.
